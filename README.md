# HR & Talent Acquisition Analytics Dashboard | Power BI

## Project Overview

This project focuses on analysing HR and talent acquisition data through an interactive Power BI dashboard.

It uses sample data to explore recruitment operations and demonstrate how business intelligence tools can support HR reporting and decision-making.

## Project Objectives

- Explore recruitment-related data.
- Monitor relevant HR and talent acquisition KPIs.
- Analyse recruitment performance.
- Present data through interactive visualisations.
- Practise turning operational data into meaningful reports.

## Tools & Technologies

- **Power BI:** Dashboard development and data visualisation
- **Sample Data:** Practice dataset for analysis
